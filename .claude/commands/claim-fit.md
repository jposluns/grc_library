Run the `claim-fit` procedure defined at [`.claude/skills/corpus-management/procedures/claim-fit.md`](../skills/corpus-management/procedures/claim-fit.md). Slash-command entry point is `/claim-fit`; the underlying procedure name remains `claim-fit`. This is the cadenced citation-precision audit of normative-attribution claims, catching the gate-blind "attributed value, silent source" class (a sentence ties a specific value to a named normative source, the source exists and the citation is well-formed so the existence and citation gates pass, but the source does not actually prescribe the attributed value). Run the one-time full Tier-A pass at adoption, after any batch that adds or edits normative-value claims, on the periodic Tier-B coverage sweep, and ad-hoc when a claim is in doubt. Execute the audit per the six-step process the procedure encodes:

1. **Establish scope and confirm the reference base**: name the scope (the full Tier-A census, a batch's claims, a flagged set, or the next Tier-B coverage sample). Confirm `.claude/skills/corpus-management/tools/run_all_audits.sh` exits 0 first. Confirm the reference base is available via its indexes, with the per-source currency rule applied (a superseded held text is grounds to defer, never to judge against silently).
2. **Build the worklist**: collect the in-scope (value, source) claims, Tier A judged exhaustively and Tier B sampled. An optional deeper review may supplement the public gates by extracting and tiering the worklist; treat any such output as input-narrowing, never a defect list. Add anything the maintainer or a prior QA note flagged.
3. **Judge each claim**: locate the named source's held text via the reference-base indexes, read the specific clause, article, or annex the claim points at, and return, for EACH (attributed value, named source) PAIR, one of `prescribed` / `informed-not-prescribed` / `mis-attributed` / `source-not-held` with the source passage QUOTED. A multi-source claim is judged once per source; the same value can draw a different verdict per source. Every judgement quotes the claim `path:line`, the attributed value, the named source, the source passage, AND the held source's own reference-base `path:line` read via an index lookup executed in THIS run, or, for `source-not-held`, the executed index lookup that returned nothing. For the Tier-B coverage sweep, sample per the procedure's stratified without-replacement discipline and name the sample in the run record; coverage counts only adjudicated rows.
4. **Apply-time-verify**: re-read each candidate `mis-attributed` and `informed-not-prescribed` source passage before confirming; refute false positives rather than routing them. Draft each confirmed fix per its verdict: rephrased attribution for `informed-not-prescribed` (the value stands; the sentence stops asserting source language that does not exist), corrected value or citation for `mis-attributed` (surfaced to the maintainer when the choice is authorial), and, for `source-not-held`, an acquisition attempt FIRST, queueing only a failed or constrained attempt. When an attribution is rephrased, search the touched file and the corpus for sibling carriers of the same value-plus-source pair at bare-token width.
5. **Triage and route**: fix confirmed in-scope findings in-window (apply, bump Version and Date, write the change record), surface authorial choices as named options, surface out-of-scope findings with named options, record refutations, cross-reference duplicates.
6. **Record and present**: surface confirmed findings inline (per (value, source) pair: claim `path:line`, attributed value, named source, verdict with the quoted source passage and its held-source reference-base `path:line`, or, for `source-not-held`, the executed index lookup that returned nothing, and the fix applied or option surfaced). Record the run in the project's own working records; a zero-finding run still gets a one-line record.

Reject any verdict that lacks an explicit claim `path:line`, a quoted source passage, AND the held source's own reference-base `path:line` (or, for `source-not-held`, the executed index lookup that returned nothing). A verdict without quoted evidence is a hypothesis, not a finding.

`claim-fit` does NOT replace the citation and existence gates; it is the precision layer on top of them. A well-formed citation says nothing about whether the source states the attributed value.

Report back: the scope and mechanical baseline, the worklist (Tier-A count, Tier-B sample), every verdict (one row per (value, source) pair: `path:line`, attributed value, named source, verdict, quoted passage, held-source reference-base `path:line`, or the executed index lookup that returned nothing for `source-not-held`), the apply-time verification outcomes (confirmed vs refuted), the fixes applied and the items routed, and where the run was recorded.
