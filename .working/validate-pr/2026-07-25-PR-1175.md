## Findings

### V1175-1, error: `manage-workers` can falsely report an unsent prompt as submitted

- **Location:** `tools/manage-workers.py:250-286`, especially `if probe in region` at line 284 and the default `submitted` result at line 286; consumed by `do_send` at lines 529-550.
- **Source line:** `return ("submitted", "the composer no longer holds the payload")`.
- **Evidence:** The check searches for an unwrapped literal 40-character probe in terminal capture text. Tmux capture inserts newlines at the pane width, so an unsent long prompt in a narrow composer does not contain the literal probe even though all of its text remains in the composer.

  Constructed Claude composer state:

  ```text
  ────────────────────────────────────────
  ❯ At your next opportunity, resync
    your grc_library scratch clone
  ────────────────────────────────────────
  auto mode
  ```

  With probe `At your next opportunity, resync your grc_library scratch clone`, `submit_state()` returned `('submitted', 'the composer no longer holds the payload')`.

- **Impact:** The caller prints `SENT`, logs the send, and stops polling. A worker that never received a submitted prompt is recorded as nudged, which is the dangerous direction the postcondition was added to prevent.
- **Classification:** In-window error. Normalize whitespace or search a wrapped-safe sequence, and add this narrow-pane fixture to the self-test.

### V1175-2, warning: token-spend parser turns non-spend numbers into worker spend and loses ordinary prose figures

- **Location:** `tools/audit-token-spend.py:53-60`, `88-100`.
- **Source line:** `re.compile(r"token[s]?\\s+spend[^0-9]{0,40}([0-9][0-9,\\.]*\\s*[kKmM]?)", re.I)`.
- **Evidence:** The unanchored pattern accepts the first number within 40 non-digits after the phrase, irrespective of whether that number is a spend. Isolated parser results:

  ```text
  "Token spend: not reported; the task budget is 8,000 tokens."  -> 8000
  "Tokens spent: none, although the allowed budget was 8,000 tokens." -> 8000
  "Approximate token spend: eight thousand tokens." -> None
  "Token spend: 8.4 thousand tokens." -> 8
  ```

- **Impact:** Advisory totals can report a budget as estimated worker spend, while a real self-reported figure can become unknown or materially undercounted. The presentation labels worker data as self-reported estimates, but it does not label parser-derived false values as uncertain.
- **Classification:** In-window warning. Parse an anchored, dedicated token-spend field first, accept a deliberately specified numeric grammar only, and retain an explicit unparsed-text status instead of scanning arbitrary nearby prose.
