## Attribution posture

The library is released under [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](LICENSE). CC BY-SA 4.0 **requires** attribution of the library when content is redistributed (in original or modified form). Its "ShareAlike" condition requires an adopter who shares an adaptation to license their own contributions to it under CC BY-SA 4.0, a later CC BY-SA version, or a BY-SA-compatible licence. The library's own text stays under CC BY-SA 4.0; quoted or vendored third-party material keeps its own terms, as [`NOTICE.md`](NOTICE.md) records.

Original GRC Library material is licensed CC BY-SA 4.0. The AI-assistant rules in `.claude/aiqt/rules/`, taken from the AIQT project (https://aiqt.ai), and the local copies rendered from them in `.claude/rules/aiqt/` and `.claude/rules/security/` are licensed Apache-2.0; if you redistribute them, include the upstream LICENSE and NOTICE files from `.claude/aiqt/`.

Attribution forms (when you share the library, any of these can meet the attribution requirement in a reasonable manner, together with indicating any changes and identifying the licence with its URI or a link to it; the canonical machine-readable form is the [`CITATION.cff`](CITATION.cff) metadata):

- An acknowledgement line in an adopter's redistributed governance documents: "Derived from the Governance, Risk, and Compliance Documentation Library (Posluns, J., CC BY-SA 4.0, https://github.com/jposluns/grc_library)".
- A reference in academic or industry publications using the citation metadata published in [`CITATION.cff`](CITATION.cff). GitHub renders a "Cite this repository" button on the repository sidebar that produces APA, BibTeX, and other formats.
- A link back to the source repository accompanied by the licence identifier.

Adopters who only consume the library internally (no redistribution) are not required to attribute the library publicly, but the same attribution forms are appreciated.

## How to cite

For machine-readable citation metadata, see [`CITATION.cff`](CITATION.cff) at the repository root. GitHub renders this as a "Cite this repository" button when viewing the repository on the web.

Example citation (APA-style):

> Posluns, J. (2026). *Governance, Risk, and Compliance Documentation Library* [Dataset]. CC BY-SA 4.0. https://github.com/jposluns/grc_library

Example citation (BibTeX):

```bibtex
@misc{posluns_grc_library_2026,
  author       = {Posluns, Jeffrey},
  title        = {Governance, Risk, and Compliance Documentation Library},
  year         = {2026},
  publisher    = {GitHub},
  howpublished = {\url{https://github.com/jposluns/grc_library}},
  note         = {CC BY-SA 4.0}
}
```

Cite the library using the citation above. For the AI-assistant rules, include the upstream Apache-2.0 LICENSE and NOTICE files as described under Attribution posture; citing the library does not replace that attribution.
